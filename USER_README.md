# Historical Airfields - Arizona

Version 2.1 · 115 historical airfields · ForeFlight Content Pack

Explore Arizona's abandoned and little-known airfields through map markers and
illustrated histories available directly in ForeFlight.

> **For historical and recreational reference only.** Do not use this package
> for navigation, landing, flight planning, or operational decisions.

## What's included

- 115 historical-airfield waypoints throughout Arizona
- Airport-style markers on the ForeFlight map
- Readable waypoint IDs beginning with `AZ_`
- One airport-named PDF attached to every waypoint
- Offline narratives, photographs, maps, captions, and contributor credits
- Links to the original source pages when internet access is available

## Install version 2.1

### Remove an earlier test version

Before installing, delete any development, version 1.x, or version 2.0 Arizona
package from **More > Custom Content > Content Packs**.

Early test editions created identifiers beginning with `AA_AZ_`, such as
`AA_AZ_336427`. Version 2.1 contains none of these identifiers. If an old one
remains after deleting its pack, remove it under **More > Custom Content > User
Waypoints**.

### Import the package

1. Transfer `Abandoned_Airports_AZ.zip` to the iPhone or iPad using AirDrop,
   Files, email, Finder, or a configured cloud provider.
2. Open the iOS Share menu and choose **ForeFlight**.
3. Confirm that **Historical Airfields - Arizona**, version 2.1, appears under
   **More > Custom Content > Content Packs**.
4. Open Maps and enable **Arizona_Historical_Airfields** in the map-layer
   selector.

Keep the file zipped when sharing it with ForeFlight.

## Use the package

Tap an airport marker or search for a waypoint ID such as
`AZ_QUEEN_CREEK_AIRFIELD`. Select the airport-named PDF from the waypoint
details to view its history.

The PDF histories and images work offline. Links to Airfields-Freeman require
an internet connection.

## Important limitations

- Coordinates are historical reference points and may be approximate.
- A location may be abandoned, redeveloped, privately owned, restricted,
  hazardous, or no longer recognizable.
- The package does not provide current runway conditions, obstacles, ownership,
  landing permission, weather, NOTAMs, or airspace information.
- A marker does not indicate that landing is possible, safe, or permitted.

## Update or remove the package

Delete the installed edition before importing a replacement. This prevents
obsolete waypoints or layer names from remaining after an update.

To remove version 2.1, open **More > Custom Content > Content Packs**, select
**Historical Airfields - Arizona**, and tap **Delete**.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The layer is named `user_waypoints` | Delete version 2.0, then import version 2.1. |
| An `AA_AZ_...` waypoint appears | Delete the earlier pack and remove any remaining legacy waypoint under User Waypoints. |
| Names appear without airport markers | Enable `Arizona_Historical_Airfields` and confirm version 2.1 is installed. |
| A history does not open | Confirm the complete ZIP imported and the device has enough free storage. |
| A source link does not open | Connect to the internet; the attached PDF itself remains available offline. |
